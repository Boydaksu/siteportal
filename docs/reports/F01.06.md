# F01.06 — Gözlemlenebilirlik, kotalar, oturum

> 2026-11-04, Europe/Istanbul. READY_FOR_REVIEW (İncelemeye ve onaya hazır). Dal `phase/F01.06-observability-quotas-auth`.

## Amaç ve önceki kabul
[F01 şartnamesi](../roadmap/F01.md), [GÜVENLİK mimarisi](../architecture/SECURITY.md) ve [SİSTEM mimarisi](../architecture/SYSTEM.md): Yapılandırılmış JSON/text loglama altyapısı, sır sızıntısını engelleyen LogMasker redaksiyonu, `Request` ve `Response` katmanlarında `X-Correlation-Id` zinciri, Prometheus uyumlu MetricsCollector, API ve kaynak hız sınırlama (RateLimiter) ile sliding window ve `Retry-After` hesaplaması, tarama ve analiz kaynak bütçesi (RequestBudget), güvenli oturum (Session: HttpOnly, SameSite, Secure, fixation engeli), 256-bit kriptografik CSRF koruması ve brute-force korumalı yönetici kimlik doğrulama servisi (AdminAuth) geliştirmek.

Önceki aşamada F01.05 teslimi kullanıcı tarafından “onaylıyorum” ile kabul edilmiş, PR #11 başarıyla `main` dalına birleştirilmiş (`8303f57e130f85f1a07ccbc8b437901e4ede7447`), kabul kaydı `737ed9f5ae422bb9dfbaec3ea897a44fbc764506` commit'lenmiş ve F01.06 geliştirme dalı açılmıştır.

## Yapılan işler ve teslim dosyaları
1. **Veritabanı Şeması ve Migration:**
   - [`database/migrations/0003_add_user_role.php`](../../database/migrations/0003_add_user_role.php): Çift yönlü (reversible) migration; `users` tablosuna `role` (VARCHAR(50) DEFAULT 'user') kolonu eklendi, varsayılan `admin@siteportal.local` admin olarak yetkilendirildi ve kalıcı hız sınırlama için `rate_limits` (`key_hash VARCHAR(64) PRIMARY KEY, hits INT, reset_at INT`) tablosu oluşturuldu.
   - [`database/seeders/0002_DevelopmentFixtureSeeder.php`](../../database/seeders/0002_DevelopmentFixtureSeeder.php): `admin@siteportal.local` kullanıcısına `role = 'admin'` yetkilendirmesi entegre edildi.

2. **Gözlemlenebilirlik ve Log Maskeleme Yapılandırması:**
   - [`config/observability.php`](../../config/observability.php): JSON ve text loglama kanalları, minimum log seviyesi, dosya yolu, LogMasker hassas anahtar listesi (`password`, `token`, `secret`, `auth`, `api_key`, `private_key`, `credit_card` vb.) ve metrik toplama ayarları.
   - [`config/auth.php`](../../config/auth.php): Oturum çerezleri (`HttpOnly`, `SameSite: Lax`, `lifetime_seconds: 1800`), admin giriş limitleri (`max_login_attempts: 5`, `lockout_seconds: 900`).
   - [`config/security.php`](../../config/security.php): Hız sınırlama (`rate_limit: 60 req/min`), tarama istek ve bayt bütçesi (`request_budget: 100 req, 50MB, 20 req/host`) ve CSRF token yapılandırması (`csrf: 7200s`).

3. **Gözlemlenebilirlik Motoru (Observability):**

     - İç içe ve çok boyutlu context dizilerinde hassas anahtarları otomatik `[REDACTED]` ile maskeleme.
     - Mesaj dizgilerinde Bearer token'lar (`Bearer [REDACTED]`), Basic auth (`Basic [REDACTED]`), veritabanı/URL içi şifreler (`mysql://user:[REDACTED]@host/db`), URL query parametreleri (`?token=[REDACTED]`), PEM özel anahtarları (`[REDACTED PRIVATE KEY]`) ve kredi kartı numaralarını (`[REDACTED CARD]`) regex ile maskeleme.
   - [`app/Core/Observability/LoggerInterface.php`](../../app/Core/Observability/LoggerInterface.php): Standart log sözleşmesi (`emergency`, `alert`, `critical`, `error`, `warning`, `notice`, `info`, `debug`, `log`).
   - [`app/Core/Observability/Logger.php`](../../app/Core/Observability/Logger.php): Yapılandırılmış JSON ve satır formatlı logger. Seviye filtreleme, `correlation_id` ve `request_id` ilişkilendirme, LogMasker ile otomatik veri arındırma, dosya ve in-memory tampon desteği.

Sayaçlar (`increment`), göstergeler (`gauge`), çalışma süresi ölçümleri (`timing`, `measure`), etiket (tag) desteği ve Prometheus formatı dışa aktarımı (`toPrometheusFormat()`).

4. **Kotalar, Hız Sınırlama ve Oturum Güvenliği (Security):**
   - [`app/Core/Security/RateLimiter.php`](../../app/Core/Security/RateLimiter.php): API ve kimlik doğrulama hız sınırlayıcı.
     - Sliding window algoritması ile `hit()`, `attempts()`, `tooManyAttempts()`, `remaining()`, `availableIn()`, `resetAttempts()`.
     - Hem bellek (in-memory) hem de SQLite/MySQL veritabanı (`rate_limits` tablosu) desteği.
     - HTTP 429 yanıtları için RFC 7231 `Retry-After` süresini saniye hassasiyetinde sağlama.
   - [`app/Core/Security/RequestBudget.php`](../../app/Core/Security/RequestBudget.php): Tarama ve analiz kaynak bütçe denetleyicisi. Analiz başına toplam istek (100) ve bayt (50MB) sınırları, host başına azami istek kotası (20), tükenme gerekçesi tespiti (`getExhaustionReason()`).
   - [`app/Core/Security/Session.php`](../../app/Core/Security/Session.php): Güvenli oturum yöneticisi. `HttpOnly`, `SameSite: Lax/Strict`, `Secure` bayrakları, son etkinlik zamanı ile hareketsizlik zaman aşımı denetimi, oturum sabitleme (fixation) koruması (`regenerate(true)`), flash mesaj desteği ve CLI/in-memory test modu.
   - [`app/Core/Security/Csrf.php`](../../app/Core/Security/Csrf.php): Çapraz istek sahteciliği koruması. 256-bit kriptografik güvenli token (`random_bytes(32)`), zamanlama saldırılarına dayanıklı `hash_equals` doğrulaması, form gizli input üretimi (`getHiddenInputHtml()`).
   - [`app/Core/Auth/AdminAuth.php`](../../app/Core/Auth/AdminAuth.php): Yönetici kimlik doğrulama servisi. `users` tablosundaki aktif admin kullanıcıları için `password_verify` kontrolü, IP ve e-posta bazlı kaba kuvvet (brute-force) engeli (5 başarısız denemede 15 dakika kilitleme), oturum sabitleme koruması, denetim günlüğü (audit logging).

5. **İstek/Yanıt ve Hata Yönetimi İyileştirmeleri:**
   - [`app/Core/Request.php`](../../app/Core/Request.php) & [`app/Core/Response.php`](../../app/Core/Response.php): `X-Correlation-Id` başlığı ve `getCorrelationId()`, `withCorrelationId()` zinciri eklendi.

   - [`app/Core/ErrorHandler.php`](../../app/Core/ErrorHandler.php): Hataların `LoggerInterface` üzerinden yapılandırılmış, correlation ID ve request ID içeren ve maskelenmiş olarak günlüğe kaydedilmesi sağlandı.

## Riskler ve teknik borç
1. **Oturum Saklama Alanı:** Mevcut sürümde session yönetimi varsayılan PHP session storage ve CLI/in-memory adapter ile çalışmaktadır. Çoklu sunucu/dağıtık mimariye geçişte (F07/F08) Redis session handler opsiyonu eklenecektir.
2. **Kaba Kuvvet (Brute-force) Anahtarı:** Admin giriş koruması IP ve e-posta birleşimi (`admin_auth:{email}|{ip}`) üzerinden kilitlenmektedir; kurumsal ağlar veya proxy arkasındaki ortamlarda kullanıcı bazlı kilitleme için ek güvenlik kontrolleri planlanmıştır.
