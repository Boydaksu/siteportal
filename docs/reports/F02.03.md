## Yapılan işler ve teslim dosyaları

1. **Kural ve Bulgu Sözleşmesi (Domain Katmanı):**
   - [`app/SeoAnalyzer/Domain/FindingStatus.php`](../../app/SeoAnalyzer/Domain/FindingStatus.php): Durum modeli enum (`PASS`, `WARN`, `FAIL`, `UNKNOWN`, `NOT_APPLICABLE`).
   - [`app/SeoAnalyzer/Domain/FindingSeverity.php`](../../app/SeoAnalyzer/Domain/FindingSeverity.php): Önem derecesi enum (`critical`, `high`, `medium`, `low`, `info`).
   - [`app/SeoAnalyzer/Domain/Confidence.php`](../../app/SeoAnalyzer/Domain/Confidence.php): Güven derecesi enum (`high`, `medium`, `low`, `unknown`).
   - [`app/SeoAnalyzer/Domain/Finding.php`](../../app/SeoAnalyzer/Domain/Finding.php): `examples/finding.schema.json` ve ADR-006 (Q-001) standartlarına tam uyumlu değişmez (immutable) değer nesnesi. `rule_id`, `rule_version`, `status`, `severity`, `confidence`, `data_source` (string), `evidence` (array of objects), `observed_at` (ISO-8601), `affected_urls`, opsiyonel `fix_key` ve `message_key` içerir. `toArray()` metodu şema ile birebir uyumlu serileştirme sağlar.
   - [`app/SeoAnalyzer/Domain/PageSnapshot.php`](../../app/SeoAnalyzer/Domain/PageSnapshot.php): Kuralların değerlendirilmesi için gerekli olan tüm gözlemleri (`requestedUrl`, `finalUrl`, `HttpResponse`, `ParsedDocument`, `robotsPolicy`, `sitemapDiscovery`, `mixedContent`, `redirectHistory`, loop ve max hops bayrakları) taşıyan değişmez bağlam nesnesi. Kuralların herhangi bir harici I/O veya ağ çağrısı yapmasını engeller (`MODULES.md` gereğince).
   - [`app/SeoAnalyzer/Domain/RuleInterface.php`](../../app/SeoAnalyzer/Domain/RuleInterface.php): Kural sözleşmesi (`getId()`, `getVersion()`, `getCategory()`, `getDefaultSeverity()`, `evaluate(PageSnapshot $snapshot): Finding`).
   - [`app/SeoAnalyzer/Domain/RuleRegistryInterface.php`](../../app/SeoAnalyzer/Domain/RuleRegistryInterface.php) ve [`app/SeoAnalyzer/Domain/RuleRegistry.php`](../../app/SeoAnalyzer/Domain/RuleRegistry.php): Kural kayıt defteri (`register`, `get`, `has`, `getByCategory`, `all`, `count`).

2. **19 Kritik Teknik SEO Kuralı (`app/SeoAnalyzer/Rules/Technical/`):**
   - [`HttpStatusRule.php`](../../app/SeoAnalyzer/Rules/Technical/HttpStatusRule.php) (`TECH_HTTP_STATUS`): HTTP 200 (PASS), 3xx (WARN), 4xx (FAIL HIGH), 5xx (FAIL CRITICAL), yanıtsız (UNKNOWN).
   - [`RedirectChainRule.php`](../../app/SeoAnalyzer/Rules/Technical/RedirectChainRule.php) (`TECH_REDIRECT_CHAIN`): 0-1 yönlendirme (PASS), 2 adım (WARN), 3+ adım aşırı zincir (FAIL).
   - [`RedirectLoopRule.php`](../../app/SeoAnalyzer/Rules/Technical/RedirectLoopRule.php) (`TECH_REDIRECT_LOOP`): Yönlendirme döngüsü veya max hops aşımı tespiti (FAIL/PASS).
   - [`HttpsRule.php`](../../app/SeoAnalyzer/Rules/Technical/HttpsRule.php) (`TECH_HTTPS`): HTTPS protokolü ve karma içerik (mixed content) tespiti (PASS / WARN / FAIL).
   - [`HttpsDowngradeRule.php`](../../app/SeoAnalyzer/Rules/Technical/HttpsDowngradeRule.php) (`TECH_HTTPS_DOWNGRADE`): Başlangıç HTTPS iken HTTP hedefine güvensiz düşüş tespiti (FAIL / PASS / NOT_APPLICABLE).
   - [`RobotsDisallowRule.php`](../../app/SeoAnalyzer/Rules/Technical/RobotsDisallowRule.php) (`TECH_ROBOTS_DISALLOW`): robots.txt tarama engeli denetimi (WARN / PASS / UNKNOWN).
   - [`RobotsUnavailableRule.php`](../../app/SeoAnalyzer/Rules/Technical/RobotsUnavailableRule.php) (`TECH_ROBOTS_UNAVAILABLE`): robots.txt 5xx sunucu hatası durumunda Google standartlarında tarama durdurma tespiti (UNKNOWN / PASS).
   - [`MetaNoindexRule.php`](../../app/SeoAnalyzer/Rules/Technical/MetaNoindexRule.php) (`TECH_META_NOINDEX`): HTML meta robots `noindex` veya `none` yönergesi tespiti (WARN / PASS / UNKNOWN).
   - [`XRobotsNoindexRule.php`](../../app/SeoAnalyzer/Rules/Technical/XRobotsNoindexRule.php) (`TECH_X_ROBOTS_NOINDEX`): HTTP yanıt başlığında `X-Robots-Tag: noindex` veya `none` tespiti (WARN / PASS / UNKNOWN).
   - [`RobotsNoindexConflictRule.php`](../../app/SeoAnalyzer/Rules/Technical/RobotsNoindexConflictRule.php) (`TECH_ROBOTS_NOINDEX_CONFLICT`): Sayfanın hem robots.txt ile engellenip hem de noindex içermesi durumunda botların noindex'i görememe çelişkisinin tespiti (FAIL conflict / PASS).
   - [`CanonicalMissingRule.php`](../../app/SeoAnalyzer/Rules/Technical/CanonicalMissingRule.php) (`TECH_CANONICAL_MISSING`): Kanonik bağlantı eksikliği tespiti (WARN info / PASS / UNKNOWN).
   - [`CanonicalEmptyRule.php`](../../app/SeoAnalyzer/Rules/Technical/CanonicalEmptyRule.php) (`TECH_CANONICAL_EMPTY`): Boş, geçersiz veya şemasız canonical href tespiti (FAIL / PASS / NOT_APPLICABLE).
   - [`CanonicalMultiConflictRule.php`](../../app/SeoAnalyzer/Rules/Technical/CanonicalMultiConflictRule.php) (`TECH_CANONICAL_MULTI_CONFLICT`): HTML ve HTTP Link başlıklarında birden fazla çelişkili kanonik URL tespiti (FAIL / PASS).
   - [`CanonicalRedirectRule.php`](../../app/SeoAnalyzer/Rules/Technical/CanonicalRedirectRule.php) (`TECH_CANONICAL_REDIRECT`): Kanonik URL'in nihai adres yerine yönlendirilen eski bir adrese işaret etmesi tespiti (WARN / PASS / NOT_APPLICABLE).
   - [`CanonicalOutOfScopeRule.php`](../../app/SeoAnalyzer/Rules/Technical/CanonicalOutOfScopeRule.php) (`TECH_CANONICAL_OUT_OF_SCOPE`): Kanonik adresin farklı bir etki alanına işaret etmesi (cross-domain canonical) tespiti (WARN / PASS / NOT_APPLICABLE).
   - [`Soft404SuspectRule.php`](../../app/SeoAnalyzer/Rules/Technical/Soft404SuspectRule.php) (`TECH_SOFT_404_SUSPECT`): HTTP 200 döndüğü halde başlıkta veya H1'de "Sayfa Bulunamadı", "404 Not Found" gibi hata ifadeleri ve zayıf içerik tespiti (WARN heuristic / PASS / NOT_APPLICABLE).
   - [`IndexabilityInferenceRule.php`](../../app/SeoAnalyzer/Rules/Technical/IndexabilityInferenceRule.php) (`TECH_INDEXABILITY_INFERENCE`): HTTP durumu, robots.txt, noindex ve yönlendirme sinyallerinin teknik indekslenebilirlik sentezi (PASS / WARN / UNKNOWN; Google sıralama garantisi iddiası içermez).
   - [`SitemapMissingRule.php`](../../app/SeoAnalyzer/Rules/Technical/SitemapMissingRule.php) (`TECH_SITEMAP_MISSING`): `/sitemap.xml` veya robots.txt içinde site haritası bulunamaması tespiti (WARN info / PASS / UNKNOWN).
   - [`SitemapStatusRule.php`](../../app/SeoAnalyzer/Rules/Technical/SitemapStatusRule.php) (`TECH_SITEMAP_STATUS`): Keşfedilen sitemap dosyalarının 4xx/5xx hata durumu tespiti (FAIL / PASS / NOT_APPLICABLE / UNKNOWN).

## Güvenlik ve Uyumluluk Notları
- **I/O İzolasyonu (MODULES.md):** Kurallar hiçbir ağ, veritabanı veya dosya sistemi çağrısı yapmaz; tüm ölçümler `PageSnapshot` üzerinden güvenli ve deterministik şekilde değerlendirilir.
- **Q-001 / ADR-006 Uyumu:** Tüm bulgularda `data_source` alanı ve nesnelerden oluşan `evidence` dizisi kullanılmıştır; sahte kanıt üretilmez.
- **Google Sıralama İddiası Yasağı:** `TECH_INDEXABILITY_INFERENCE` kuralı dahil hiçbir kural Google'ın sıralama faktörlerini veya dizin garantisini kesin biliyormuş gibi raporlamaz; teknik sinyallere dayalı ölçüm ve feragatname (disclaimer) sunar.
- **Sır Sızıntısı:** `verify_inventory.py` taramasında sıfır sır / sızıntı doğrulandı.
