# F01.03 — URL doğrulama / SSRF koruması

> 2026-11-04, Europe/Istanbul. READY_FOR_REVIEW. Dal `phase/F01.03-ssrf-protection`.

## Amaç ve önceki kabul
[F01 şartnamesi](../roadmap/F01.md): URL parser allowlist şema/port, IPv4/IPv6 public IP denetimi, DNS pinning, redirect yeniden doğrulama ve outbound network kısıt politikasını hayata geçirmek.
Önceki aşamada F01.02 teslimi kullanıcı tarafından “onaylıyorum” ile kabul edilmiş, PR #8 başarıyla `main` dalına birleştirilmiş (`e93038cabbb1e26c63890c501e07fd0776303540`) ve F01.03 geliştirme dalı açılmıştır.

## Yapılan işler ve teslim dosyaları
1. **Güvenlik İstisnaları ve Hata Eşlemeleri (Security Exceptions):**
   - [`app/Core/Security/Exceptions/SecurityException.php`](../../app/Core/Security/Exceptions/SecurityException.php): Temel güvenlik istisnası (`getErrorCode()`).
   - [`app/Core/Security/Exceptions/InvalidUrlException.php`](../../app/Core/Security/Exceptions/InvalidUrlException.php): Geçersiz URL formatı (`INVALID_URL`).
   - [`app/Core/Security/Exceptions/BlockedUrlException.php`](../../app/Core/Security/Exceptions/BlockedUrlException.php): SSRF / engellenen adres (`URL_BLOCKED`). ERROR_STATES standardına uygun olarak iç IP adreslerini sızdırmaz.
   - [`app/Core/Security/Exceptions/DnsResolutionException.php`](../../app/Core/Security/Exceptions/DnsResolutionException.php): DNS çözümleme hatası (`DNS_FAILED`).
   - [`app/Core/Security/Exceptions/RedirectException.php`](../../app/Core/Security/Exceptions/RedirectException.php): Yönlendirme döngüsü (`REDIRECT_LOOP`) ve hop sınırı (`REDIRECT_LIMIT`).

2. **Dış Ağ Güvenlik Politikası ve IP Doğrulama (Security Policy & IP Validator):**
   - [`app/Core/Security/UrlSecurityPolicy.php`](../../app/Core/Security/UrlSecurityPolicy.php): İzinli şemalar (`http`, `https`), izinli portlar (`80`, `443`), maksimum yönlendirme (5), engellenen TLD'ler (`.local`, `.internal`, `.lan`, `.test`, `.example`, `.onion` vb.), engellenen ana makineler (`localhost`, `metadata.google.internal`) ve engellenen IPv4/IPv6 CIDR blokları.
   - [`app/Core/Security/IpValidator.php`](../../app/Core/Security/IpValidator.php): İkili `inet_pton` tabanlı yüksek performanslı CIDR eşleştiricisi. RFC 1918, RFC 3927 (169.254.x.x cloud metadata), loopback, link-local, ULA, multicast ve IPv4-mapped IPv6 adreslerini eksiksiz denetler. `allowPrivateIps` varsayılan olarak kapalıdır (fail-closed).
   - [`config/security.php`](../../config/security.php): Ortam değişkenleriyle yapılandırılabilir güvenlik ayarları.

3. **DNS Çözümleme ve DNS Pinning:**
   - [`app/Core/Security/DnsResolverInterface.php`](../../app/Core/Security/DnsResolverInterface.php): DNS arayüz sözleşmesi.
   - [`app/Core/Security/SystemDnsResolver.php`](../../app/Core/Security/SystemDnsResolver.php): `dns_get_record()` ve `gethostbynamel()` sistem DNS çözümleyicisi.
   - [`app/Core/Security/PinnedTarget.php`](../../app/Core/Security/PinnedTarget.php): Doğrulanmış ve çözümlenmiş IP adresini donduran (pinning) değişmez veri nesnesi. `getCurlResolveOption()` ile DNS Rebinding (TOCTOU) saldırılarını tamamen engeller.

4. **URL Doğrulayıcı ve Yönlendirme Denetimi (UrlValidator & RedirectValidator):**
   - [`app/Core/Security/UrlValidator.php`](../../app/Core/Security/UrlValidator.php): URL sözdizimi, karakter temizliği (kontrol karakteri, ters eğik çizgi, kullanıcı bilgisi user:pass engeli), standart port kontrolü, sekizlik/onluk/onaltılık IP hilelerinin tespiti, alan adı FQDN kontrolü ve fail-closed DNS doğrulamasını koordine eder.
   - [`app/Core/Security/RedirectValidator.php`](../../app/Core/Security/RedirectValidator.php): HTTP yönlendirmelerinde (301, 302, 303, 307, 308) göreli adres çözümlemesi (`/`, `//`, `?`, `../`), yönlendirme döngüsü tespiti, maksimum sekme sayısı kontrolü ve hedef URL'nin eksiksiz yeniden doğrulanması (kamusal sunucudan iç ağa pivot engelleme).

5. **Testler ve Güvenlik Vektörleri:**
   - [`tests/Fixtures/SsrfVectors.php`](../../tests/Fixtures/SsrfVectors.php): Dahili, bulut metadata, IPv6 hileleri, parser karmaşası ve standart kamu IP/URL test vektörleri.
   - [`tests/Fixtures/MockDnsResolver.php`](../../tests/Fixtures/MockDnsResolver.php): Deterministik ve DNS rebinding simülasyonu sağlayan test çözümleyicisi.
   - [`tests/Unit/Security/IpValidatorTest.php`](../../tests/Unit/Security/IpValidatorTest.php) (8 test, 122 assertion).
   - [`tests/Unit/Security/UrlValidatorTest.php`](../../tests/Unit/Security/UrlValidatorTest.php) (11 test, 112 assertion).
   - [`tests/Unit/Security/RedirectValidatorTest.php`](../../tests/Unit/Security/RedirectValidatorTest.php) (8 test, 13 assertion).
   - [`tests/Unit/Security/DnsPinningTest.php`](../../tests/Unit/Security/DnsPinningTest.php) (3 test, 7 assertion).
   - [`tests/Integration/Security/SecurityIntegrationTest.php`](../../tests/Integration/Security/SecurityIntegrationTest.php) (3 test, 16 assertion).
