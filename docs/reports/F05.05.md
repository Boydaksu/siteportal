## 1. Kapsam ve Yapılan Geliştirmeler

F05.05 şartnamesinde (`docs/roadmap/F05.md`) belirtilen Google Search Console URL Inspection API entegrasyonu, dizin durumu (`indexed status`), kapsam (`coverage state`), robots.txt, canonical ve mobil uyumluluk kontrolleri tamamlanmıştır:

1. **Veritabanı Migration (`database/migrations/0012_create_url_inspection_tables.php`):**
   - `url_inspection_caches` tablosu: `site_id`, `url_hash` (sha256), `inspection_url`, `gsc_site_url`, `index_verdict`, `coverage_state`, `robots_txt_state`, `indexing_state`, `last_crawl_time`, `page_fetch_state`, `google_canonical`, `user_canonical`, `crawled_as`, `raw_payload_json`, `fetched_at`, `expires_at`, `created_at`.
   - İndeksler: Tekillik ve arama indeksleri (`uk_url_inspection_site_hash`, `idx_url_inspection_expiry`).
   - `ObservabilityIntegrationTest` 12 migration kontrolü ile güncellendi ve 6/6 test geçti.

2. **DTO ve Domain Modelleri (`app/Core/SearchConsole/Models/`):**
   - `UrlInspectionIndexStatus`: verdict (`PASS`, `NEUTRAL`, `FAIL`, `VERDICT_UNSPECIFIED`), coverageState, robotsTxtState, indexingState, lastCrawlTime, pageFetchState, googleCanonical, userCanonical, crawledAs, referringUrls, sitemaps.
   - `UrlInspectionMobileUsability`: verdict, issues listesi (`issueType`, `severity`, `message`).
   - `UrlInspectionRichResults`: verdict, detectedItems listesi.
   - `UrlInspectionResult`: Tip güvenli taşıyıcı model, `isLiveTest` (daima `false`), `metadataSource` (`GSC_INDEX_INSPECTION`), `isCached`, `cachedAt`.

3. **İstemci ve Servis Katmanı (`app/Core/SearchConsole/Services/`):**
   - **`UrlInspectionClientInterface` & `GoogleUrlInspectionClient`:**
     - Google Search Console URL Inspection API v1 istemcisi (`https://searchconsole.googleapis.com/v1/urlInspection/index:inspect`).
     - 401 Unauthorized -> `GscNotConnectedException`, 403 Forbidden -> `GscPermissionException`, 429 Too Many Requests -> `GscQuotaExceededException`, generic hatalar -> `SearchConsoleException`.
   - **`UrlInspectionService`:**
     - Site erişim ve yetki kontrolü (`assertUserCanAccessSite`).
     - URL alan adı ve origin uyum doğrulaması (`validateInspectionUrl` — sitenin origin'i dışındaki URL'lerin sorgulanmasını engeller).
     - 24 saatlik TTL veritabanı önbelleklemesi (`url_inspection_caches`) ile günlük 2.000 istek kotasının korunması.
     - İsteğe bağlı önbellek atlama (`forceRefresh: true`).
     - Süresi dolan token'ların `GoogleOAuthService::getValidAccessToken` üzerinden otomatik yenilenmesi (`refreshAccessToken`).
     - **Sözleşme Kuralı 1 (Canlı URL testi iddiası yok):** Rapor daima Google'ın dizinindeki son bilinen durumu yansıtır (`isLiveTest = false`, `metadataSource = 'GSC_INDEX_INSPECTION'`).
     - **Sözleşme Kuralı 2 (Teknik SEO skor izolasyonu):** URL Inspection sonuçları crawler'ın teknik SEO skorunu (`analyses.score_overall`) kesinlikle değiştirmez veya etkilemez.

4. **İki Dilli (tr-TR & en-US) Sözlük:**
   - `resources/lang/tr-TR/messages.php` ve `resources/lang/en-US/messages.php` içine 14 yeni URL Inspection anahtarı eklendi (%100 senkronize, 294 anahtar).
