## 1. Kapsam ve Yapılan Geliştirmeler

F05.03 şartnamesinde (`docs/roadmap/F05.md`) belirtilen PKCE (RFC 7636), anti-CSRF / replay-guarded state mekanizması, AES-256-GCM authenticated at-rest token şifreleme, minimum read-only yetki ilkesi (least privilege), otomatik token yenileme ve Google revocation mimarisi eksiksiz geliştirilmiştir:

1. **Veritabanı Migration (`database/migrations/0010_create_oauth_tables.php`):**
   - `oauth_connections` tablosu oluşturuldu (`id`, `user_id`, `site_id`, `provider`, `provider_user_id`, `provider_email`, `access_token_encrypted`, `refresh_token_encrypted`, `token_type`, `scopes`, `expires_at`, `status`, `revoked_at`, `created_at`, `updated_at`).
   - `oauth_states` tablosu oluşturuldu (`id`, `state`, `user_id`, `site_id`, `provider`, `code_verifier`, `scopes`, `used_at`, `expires_at`, `created_at`).
   - İndeksler ve tekillikler: `uk_oauth_states_state`, `idx_oauth_connections_user_provider`, `idx_oauth_connections_site_provider`, `idx_oauth_states_expires`.

2. **Kriptografi ve Güvenlik Altyapısı (`app/Core/OAuth/Security/`):**
   - **`TokenEncryptionService`:**
     - OpenSSL tabanlı AES-256-GCM authenticated encryption.
     - 12-byte kriptografik rastgele IV (`random_bytes(12)`).
     - 16-byte MAC tag ile kurcalama tespiti (tamper detection).
     - `APP_KEY` üzerinden SHA-256 anahtar türetimi.
     - Şifreli JSON serileştirmesi (`iv`, `tag`, `data`).
   - **`PkceService`:**
     - RFC 7636 uyumlu kriptografik `code_verifier` üretimi (43-128 karakter, URL-safe base64).
     - SHA-256 hash tabanlı `S256` code challenge üretimi (`BASE64URL(SHA256(code_verifier))`).
     - RFC 7636 Appendix B test vektörü (`dBjftJeZ4CVP-mB92K27uhbUJU1p1r_wW1gFWFOEjXk` -> `E9Melhoa2OwvFrEMTJguCHaoeK1t8URWbuGJSstw-cM`) ile %100 uyumluluk.
     - Kriptografik rastgele 32-byte (64 hex) `state` üreticisi.

3. **Modeller ve Veri Transfer Nesneleri (`app/Core/OAuth/Models/`):**
   - `OAuthConnection`: Aktif/revoked durum denetimi, JSON-decoded scopes, tip güvenli entity.
   - `OAuthTokenResponse`: Token takası ve yenileme yanıtlarını taşıyan tip güvenli model.

4. **Hata Sınıfları (`app/Core/OAuth/Exceptions/`):**
   - `OAuthException`, `TokenDecryptionException`, `InvalidStateException`, `OAuthTokenExpiredException`, `OAuthRevocationException`, `OAuthScopeException`.

5. **Google OAuth Servisi (`GoogleOAuthService`):**
   - **Yetkilendirme URL'si (`createAuthorizationUrl`):**
     - PKCE code verifier ve challenge üretimi.
     - Zorunlu `state` üretimi ve veritabanına 10 dakika TTL ile kaydı.
     - Minimum read-only yetki ilkesi: İzin verilmeyen yazma kapsamları talep edildiğinde derhal `OAuthScopeException` fırlatılır. Varsayılan scope: `webmasters.readonly`, `openid`, `email`.
     - Google OAuth v2 auth URL parametreleri (`code_challenge_method=S256`, `access_type=offline`, `prompt=consent`).
   - **Callback İşleme (`handleCallback`):**
     - State doğrulaması: Süre aşımı (TTL), daha önce kullanılmış olma (replay guard) ve istek sahibi kullanıcı ile uyuşmama (cross-tenant state hijacking) kontrolleri.
     - State'in tüketimi (`used_at = NOW()`).
     - PKCE `code_verifier` ile Google token endpoint'e POST takas çağrısı.
     - ID Token JWT payload çözümleme (`sub`, `email`).
     - Sunucu tarafında `access_token` ve `refresh_token` verilerinin AES-256-GCM ile şifrelenerek veritabanına yazılması.
   - **Geçerli Token Erişimi ve Otomatik Yenileme (`getValidAccessToken`):**
     - Token süresi dolmamışsa (60 saniye güvenlik marjı ile) deşifre edilip döndürülür.
     - Token süresi dolmuşsa `refresh_token` otomatik deşifre edilerek Google'dan yeni `access_token` alınır, şifrelenip DB'de güncellenir.
   - **Erişim İptali (`revokeAccess`):**
     - Google `https://oauth2.googleapis.com/revoke` endpoint'ine iptal çağrısı.
     - Yerel DB'deki `access_token_encrypted` ve `refresh_token_encrypted` alanlarının tamamen boşaltılması ve `status = revoked` yapılması.

6. **İki Dilli (tr-TR & en-US) Sözlük Genişletmesi:**
   - `resources/lang/tr-TR/messages.php` ve `resources/lang/en-US/messages.php` dosyalarına 13 adet yeni OAuth ve kullanıcı onay (consent) çeviri anahtarı eklendi; sözlükler %100 senkronize (266 anahtar).
