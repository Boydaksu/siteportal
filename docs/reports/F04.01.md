# F04.01 — PageSpeed Insights Bağlayıcısı Teslim Raporu

## 1. Amaç ve Kapsam
`F04 — V1.2: Performans, mobil, yapılandırılmış veri` ana fazının ilk alt aşaması olan **F04.01**, Google PageSpeed Insights API v5 entegrasyonu ile mobil ve masaüstü ortamlarda sentetik Lighthouse performans lab ölçümlerini sisteme kazandırır.

Bu alt faz kapsamında:
1. **Mobil ve Masaüstü Lab Ölçümleri:** Her iki form faktörü (`PageSpeedStrategy::MOBILE` ve `PageSpeedStrategy::DESKTOP`) için FCP, LCP, TBT, CLS, Speed Index ve TTI metriklerinin toplanması,
2. **Scored vs Raw Metrik Ayrımı:** Sayısal ham ölçüm değerleri (ms veya birimsiz) ile Lighthouse puanlama sisteminin (0-100 ölçeği ve `good`, `needs_improvement`, `poor` durumları) birbirinden net olarak ayrılması,
3. **Fail-Safe Hata Toleransı:** Google API kesintilerinde (ağ zaman aşımı, 429 kota aşımı, 5xx sunucu hatası, bozuk JSON veya eksik API anahtarı) genel SEO raporunun veya analiz motorunun kesinlikle bozulmaması; sahte sıfır puan yerine `status: UNKNOWN` veya `NOT_MEASURED` durumunun korunması,
4. **Veri Kaynağı ve Feragatname Şeffaflığı:** Tüm sonuçlarda `data_source: "google_pagespeed_api"` ve `is_lab_data: true` etiketleri ile bunların sentetik laboratuvar simülasyonu olduğu ve gerçek kullanıcı alanı verisi (CrUX) olmadığı açıkça belirtilmesi,
5. **Kota Korumalı Güvenli Önbellek:** TTL destekli bellek önbelleği (`MemoryPageSpeedCache`) ile aynı URL ve strateji için yinelenen API isteklerinin önlenmesi ve API bütçesinin korunması,
gerçekleştirilmiş ve testlerle doğrulanmıştır.

## 2. Geliştirilen Bileşenler ve Mimarî

1. **Yapılandırma (`config/pagespeed.php`):**
   - API anahtarı (`PAGESPEED_API_KEY`), endpoint URL'si, istek zaman aşımı (15 saniye), varsayılan strateji (`mobile`) ve önbellek yaşam süresi (3600 saniye / 1 saat).

2. **Strateji ve Metrik Durum Enum'ları (`PageSpeedStrategy`, `PageSpeedMetricStatus`):**
   - `PageSpeedStrategy`: `MOBILE = 'mobile'`, `DESKTOP = 'desktop'`.
   - `PageSpeedMetricStatus`: `GOOD = 'good'`, `NEEDS_IMPROVEMENT = 'needs_improvement'`, `POOR = 'poor'`, `UNKNOWN = 'unknown'`.

3. **Lab Metrikleri Modeli (`PageSpeedLabMetrics`):**
   - FCP, LCP, TBT, CLS, Speed Index ve TTI için ham değer (`raw_value`), gösterim metni (`display_value`), Lighthouse skoru (`score`: 0-100) ve standart Google Core Web Vitals eşiklerine göre hesaplanan durum (`status`).

4. **Bağlayıcı Sonuç Değer Nesnesi (`PageSpeedResult`):**
   - URL, strateji, başarı durumu (`success`), genel performans skoru (0-100), lab metrikleri, hata nedeni (`errorReason`), getirilme zamanı (`fetchTime`), önbellek bayrağı (`fromCache`), veri kaynağı (`data_source: 'google_pagespeed_api'`) ve lab verisi bayrağı (`is_lab_data: true`).
   - Başarısız durumlarda `PageSpeedResult::unavailable($url, $strategy, $reason)` ile sisteme güvenli varsayılan sağlama.

5. **Önbellek Sözleşmesi ve Bellek Sürücüsü (`PageSpeedCacheInterface`, `MemoryPageSpeedCache`):**
   - `get`, `set`, `has`, `clear` metotları ve URL + strateji bazında bağımsız anahtarlama (`url#strategy`). Süresi dolan kayıtları otomatik temizleme.

6. **PageSpeed İstemcisi (`PageSpeedClientInterface`, `PageSpeedClient`):**
   - `SafeHttpClient` veya enjekte edilen `HttpClientInterface` üzerinden Google API'sine güvenli çağrı.
   - HTTP 429, 5xx, cURL/ağ hataları ve bozuk JSON durumlarında exception fırlatmadan fail-safe yönetim.

7. **Çoklu Dil Desteği (`resources/lang/`):**
   - `tr-TR` ve `en-US` sözlüklerinde lab verisi feragatnamesi ve arayüz etiketleri.
